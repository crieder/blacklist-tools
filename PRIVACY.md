Das Sitzungs-Cookie bleibt nur im Arbeitsspeicher und wird beim Beenden von Thunderbird oder Deaktivieren des Add-ons verworfen.

Das Add-on wird von GitHub (Microsoft, USA) heruntergeladen, und Thunderbird ruft die Update-Information regelmäßig von GitHub ab (`raw.githubusercontent.com`). GitHub erhält dabei Deine IP-Adresse; es gelten die Datenschutzhinweise von GitHub, die auch die Übermittlung in die USA regeln (u. a. EU-US Data Privacy Framework). # Privacy Policy – Blacklist-Tools
As of: 12 Nov 2026

Provider: Carsten Rieder, Software.Solutions.ForYou.at ([Imprint](https://software.solutions.foryou.at/impressum/)), email: office@software.solutions.foryou.at

**The add-on does not collect, send or share any data with us or with third parties.** It has no analytics, no telemetry and no external services of its own. We do not process the personal data you handle with the add-on (for example sender addresses in your mail); if you use it for work, you are responsible for that processing yourself.

## What stays inside Thunderbird
- *Message filters:* conditions are written to your own Thunderbird filter list (`msgFilterRules.dat` in your profile).
- *Settings:* stored in Thunderbird's extension storage on your computer.
- *ISPConfig password:* stored in Thunderbird's password manager on your computer (protected by your primary password, if you set one).
- *Log file (only if you turn it on):* `blacklist-tools.log` in your Thunderbird profile folder. Passwords, session IDs and form tokens are masked; **blocked email addresses appear in plain text**. You can delete it at any time from the settings.

## What is sent over the network
Only if you configure the optional ISPConfig feature, and only to **the ISPConfig server address you enter yourself** (HTTPS only; the server belongs to you or your hoster): your ISPConfig user name and password to log in, the email addresses you add to or delete from the blacklist, and requests to read the blacklist. The session cookie is kept in memory only and discarded when Thunderbird closes or the add-on is disabled.

## Download and updates
The add-on is downloaded from GitHub (Microsoft, USA), and Thunderbird regularly fetches the update information from GitHub (`raw.githubusercontent.com`). GitHub receives your IP address in the process; GitHub's privacy statement applies, including its rules on transfers to the USA (among others the EU-US Data Privacy Framework). The add-on itself transmits no data in doing so.

## Contact and your rights
If you write to us, we process your message and email address to reply (Art. 6(1)(b) or (f) GDPR) and delete them when the request is dealt with and no retention duty applies. **Posts in public GitHub issues are visible to everyone; please do not include personal data there.** You have the rights under Art. 15–21 GDPR (access, rectification, erasure, restriction, portability, objection) to the extent we hold data about you; write to the email address above. Complaints: the Austrian Data Protection Authority, www.dsb.gv.at. The website itself is covered by the [website privacy policy](https://software.solutions.foryou.at/datenschutz/).
