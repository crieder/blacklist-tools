**The add-on does not collect, send or share any data with us or with third parties.** It has no analytics, no telemetry and no external services of its own. We do not process the personal data you handle with the add-on (for example sender addresses in your mail); if you use it for work, you are responsible for that processing yourself.

## What stays inside Thunderbird

- **Message filters:** conditions are written to your own Thunderbird filter list (`msgFilterRules.dat` in your profile).
- **Settings** are stored in Thunderbird's extension storage on your computer.
- **ISPConfig password:** stored in Thunderbird's password manager on your computer (protected by your primary password, if you set one).
- **Log file (only if you turn it on):** `blacklist-tools.log` in your Thunderbird profile folder. Passwords, session IDs and form tokens are masked; **blocked email addresses appear in plain text**. You can delete it at any time from the settings.

## What is sent over the network

Only if you configure the optional ISPConfig feature, and only to **the ISPConfig server address you enter yourself** (HTTPS only; the server belongs to you or your hoster):

- your ISPConfig user name and password, to log in;
- the email addresses you choose to add to or delete from the blacklist;
- requests to read the blacklist.

The ISPConfig session cookie is kept in memory only, used only for these requests, and discarded when Thunderbird closes or the add-on is disabled.

## Download and updates

The add-on is downloaded from GitHub, and Thunderbird regularly fetches the update information from GitHub (`raw.githubusercontent.com`). GitHub receives your IP address in the process; GitHub's privacy statement applies. The add-on itself transmits no data in doing so.

## Was in Thunderbird bleibt

- **Nachrichtenfilter:** Bedingungen werden in Deine eigene Thunderbird-Filterliste geschrieben (`msgFilterRules.dat` im Profil).
- **Einstellungen:** im Erweiterungsspeicher von Thunderbird auf Deinem Rechner.
- **ISPConfig-Passwort:** in der Thunderbird-Passwortverwaltung auf Deinem Rechner (geschützt durch Dein Hauptpasswort, falls gesetzt).
- **Logdatei (nur wenn eingeschaltet):** `blacklist-tools.log` im Profilordner. Passwort, Sitzungs-ID und Formular-Token sind maskiert; **gesperrte E-Mail-Adressen stehen im Klartext**. Löschbar jederzeit in den Einstellungen.

## Was über das Netz geht

Nur wenn Du die optionale ISPConfig-Funktion einrichtest, und nur an **die von Dir eingetragene ISPConfig-Adresse** (nur HTTPS; der Server gehört Dir oder Deinem Hoster):

- Benutzername und Passwort zum Anmelden;
- die Adressen, die Du sperrst oder löschst;
- Abfragen der Blacklist.

Das Sitzungs-Cookie bleibt nur im Arbeitsspeicher, dient nur diesen Anfragen und wird beim Beenden von Thunderbird oder Deaktivieren des Add-ons verworfen.

## Download und Updates

Das Add-on wird von GitHub heruntergeladen, und Thunderbird ruft die Update-Information regelmäßig von GitHub ab (`raw.githubusercontent.com`). GitHub erhält dabei Deine IP-Adresse; es gelten die Datenschutzhinweise von GitHub. Das Add-on selbst überträgt dabei keine Daten.
